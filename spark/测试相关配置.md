### 1. spark-env.sh 配置（主要来源于图1）

该文件主要定义 Spark 进程运行时依赖的环境变量、JVM参数及Hadoop/Java路径。

- **基础环境与依赖路径**
    
    - `export JAVA_HOME=/opt/java/jdk-21.0.2`
        
    - `export HADOOP_HOME=/usr/hdp/3.3.2.0-001/hadoop`
        
    - `export HADOOP_CONF_DIR=/usr/hdp/3.3.2.0-001/hadoop/conf`
        
    - `export LD_LIBRARY_PATH=$HADOOP_HOME/lib/native/:$LD_LIBRARY_PATH`
        
- **Spark 配置路径**
    
    - `export SPARK_CONF_DIR=/usr/hdp/3.3.2.0-001/spark3-historyserver/conf`
        
    - `export SPARK_LOG_DIR=/var/log/spark4`
        
    - `export SPARK_PID_DIR=/var/run/spark4`
        
- **Daemon 进程参数**
    
    - `export SPARK_DAEMON_MEMORY=2048m` (Master, Worker及History Server内存)
        
    - `export SPARK_IDENT_STRING=$USER`
        
    - `export SPARK_NICENESS=0`
        
- **注释掉的历史服务Kerberos示例**
    
    - `#export SPARK_HISTORY_OPTS='-Dspark.ui.filters=org.apache.hadoop.security.authentication.server.AuthenticationFilter -Dspark.org.apache.hadoop.security.authentication.server.AuthenticationFilter.params="type=kerberos,kerberos.principal=HTTP/dsjpt1@UDZ2024KYLIN.COM,kerberos.keytab=...'`

### 2. spark-defaults.conf 配置（主要来源于图2、图3）

该文件定义了 Spark 任务运行时的属性，包括 Catalog（Iceberg/Paimon）、历史服务、Hive元数据、资源调度等。

- **Spark 历史服务 (History Server)**
    
    - `spark.history.fs.logDirectory hdfs://<IP>/spark4-history/`
        
    - `spark.history.kerberos.enabled true`
        
    - `spark.history.kerberos.principal dsjpt1@UDZ2024KYLIN.COM`
        
    - `spark.history.kerberos.keytab /etc/security/keytabs/spark.service.keytab`
        
    - `spark.history.store.path /var/lib/spark4/shs_db`
        
    - `spark.history.fs.cleaner.enabled true`, `cleaner.interval 7d`, `cleaner.maxAge 90d`
        
    - `spark.history.ui.port 18084` (端口冲突警告: 图2中设置 `18084`，图3中有 `spark.history.ui.port 18884`，根据第2张图截图，应为18084)
        
    - `spark.history.provider org.apache.spark.deploy.history.FsHistoryProvider`
        
    - `spark.history.ui.acls.enable true`, `spark.history.ui.admin.acls` (空)
        
    - `spark.hadoop.yarn.timeline-service.enabled false`
        
- **Catalog 配置 (Hive、Iceberg、Paimon)**
    
    - **Hive Catalog**: `spark.sql.catalog.hive` (使用 `org.apache.kyuubi.spark.connector.hive.HiveTableCatalog` 或开启原生Hive集成)
        
    - **Iceberg Catalog**: `spark.sql.catalog.iceberg` (类型 `hive`, 认证使用Kerberos, `warehouse hdfs://<IP>:8020/warehouse/iceberg/warehouse`)
        
    - **Paimon Catalog**: `spark.sql.catalog.paimon` (类型 `hive`, `warehouse hdfs://<IP>:8020/warehouse/paimon/warehouse`)
        
    - _扩展配置_: `spark.sql.extensions org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions,org.apache.paimon.spark.extensions.PaimonSparkSessionExtensions`
        
- **Hive Metastore 配置**
    
    - `spark.sql.hive.metastore.version 4.1.0`
        
    - `spark.sql.hive.metastore.jars.path file:///usr/hdp/3.3.2.0-001/spark-4.1.2-bin-hadoop3.3/standalone-metastore/*`
        
    - `spark.sql.hive.convertMetastoreOrc true`
        
- **YARN 与资源调度**
    
    - `spark.master yarn`
        
    - `spark.yarn.queue default`
        
    - `spark.yarn.archive hdfs://<IP>:8020/spark4/spark4-hdp-archive/spark-4.1.2-bin-hadoop3.3/spark4-hdp-archive.tar.gz`
        
    - `spark.yarn.jars` (指向依赖包路径)
        
- **Executor 与 Driver**
    
    - `spark.executor.extraJavaOptions -Xmx256m -XX:UseNUMA` (需注意实际通常也配置 driver 内存)
        
    - `spark.driver.extraJavaOptions -Dhdp.version=3.3.2.0-001`
        
    - `spark.executor.extraLibraryPath /usr/hdp/current/hadoop-client/lib/native:/usr/hdp/current/hadoop-client/lib/native/Linux-amd64-64`
        
    - `spark.driver.extraLibraryPath /usr/hdp/current/hadoop-client/lib/native:/usr/hdp/current/hadoop-client/lib/native/Linux-amd64-64`
        
- **Shuffle 与 IO 性能优化**
    
    - `spark.sql.adaptive.enabled true`
        
    - `spark.io.compression.lz4.blockSize 128kb`
        
    - `spark.sql.autoBroadcastJoinThreshold 26214400` (25MB)
        
    - `spark.shuffle.file.buffer 1m`
        
    - `spark.shuffle.io.backlog 8192`
        
    - `spark.shuffle.io.serverThreads 120`
        
- **UI 与 安全 ACL**
    
    - `spark.acls.enable true`
        
    - `spark.admin.acls`
        
    - `spark.ui.acls.enable true`
        
- **其他**
    
    - `spark.sql.queryExecutionListeners`
        
    - `spark.sql.statistics.fallBackToHdfs true`

### 3. kyuubi-defaults.conf 配置（主要来源于图4）

定义了 Kyuubi 服务本身的启动参数，主要包含认证、高可用(HA)、连接端口、Engine类型等。

- **认证与 Kerberos**
    
    - `kyuubi.authentication KERBEROS`
        
    - `kyuubi.frontend.kerberos.principal HIVE/_HOST@UDZ2024KYLIN.COM`
        
    - `kyuubi.frontend.kerberos.keytab /etc/security/keytabs/hive.service.keytab`
        
    - `kyuubi.engine.kerberos.principal HIVE/_HOST@UDZ2024KYLIN.COM`
        
    - `kyuubi.engine.kerberos.keytab /etc/security/keytabs/hive.service.keytab`
        
    - `kyuubi.ha.zookeeper.auth.type KERBEROS`
        
    - `kyuubi.ha.zookeeper.kerberos.principal hive/_HOST@UDZ2024KYLIN.COM`
        
    - `kyuubi.ha.zookeeper.kerberos.keytab /etc/security/keytabs/hive.service.keytab`
        
- **前端端口与协议**
    
    - `kyuubi.frontend.bind.host 10.0.0.1` (或者配置为 `0.0.0.0`)
        
    - `kyuubi.frontend.protocols THRIFT_BINARY,REST`
        
    - `kyuubi.frontend.thrift.binary.bind.port 10009`
        
    - `kyuubi.frontend.rest.bind.port 10099`
        
- **Engine 引擎与会话**
    
    - `kyuubi.engine.type SPARK_SQL`
        
    - `kyuubi.engine.share.level USER`
        
    - `kyuubi.session.engine.initialize.timeout PT2M`
        
- **高可用 (HA) 与 Zookeeper**
    
    - `kyuubi.ha.addresses zk1:2181,zk2:2181,zk3:2181`
        
    - `kyuubi.ha.namespace kyuubi`
        
    - `kyuubi.ha.client.class org.apache.kyuubi.ha.client.zookeeper.ZookeeperDiscoveryClient`
        
    - `kyuubi.ha.zookeeper.quorum hfhdpp86:2181,hfhdpp87:2181,hfhdpp88:2181`
        
    - `kyuubi.ha.zookeeper.session.timeout 600000`
        
    - `kyuubi.ha.zookeeper.acl.enabled true`

### 4. kyuubi-env.sh 配置（主要来源于图5）

定义了 Kyuubi 运行时层面的环境变量，用于指定底层引擎路径、JVM参数。

- **基础组件路径**
    
    - `export JAVA_HOME=/opt/java/jdk-21.0.2`
        
    - `export HADOOP_HOME=/usr/hdp/3.3.2.0-001/hadoop`
        
    - `export HADOOP_CONF_DIR=/usr/hdp/3.3.2.0-001/hadoop/conf`
        
    - `export YARN_CONF_DIR=/usr/hdp/3.3.2.0-001/hadoop/conf`
        
    - `export SPARK_HOME=/usr/hdp/3.3.2.0-001/spark-4.1.2-bin-hadoop3.3`
        
    - `export SPARK_CONF_DIR=/usr/hdp/3.3.2.0-001/spark-4.1.2-bin-hadoop3.3/conf`
        
    - `export FLINK_HOME=/opt/flink` (注释掉的示例)
        
    - `export HIVE_HOME=/opt/hive` (注释掉的示例)
        
- **Kyuubi 服务日志与 PID**
    
    - `export KYUUBI_LOG_DIR=/var/log/kyuubi`
        
    - `export KYUUBI_PID_DIR=/var/run/kyuubi`
        
    - `export KYUUBI_WORK_DIR_ROOT`
        
- **JVM 与 GC 调优**
    
    - `export KYUUBI_CTL_JAVA_OPTS="-Xmx10g -Xms10g -XX:MaxMetaspaceSize=512m -XX:MaxDirectMemorySize=1024m -XX:+UseG1GC -XX:+UseGCOverheadLimit -XX:+HeapDumpOnOutOfMemoryError -XX:HeapDumpPath=/logs -XX:+PrintGCDetails -XX:+PrintGCDateStamps -XX:+UseGCLogFileRotation -XX:NumberOfGCLogFiles=10 -XX:GCLogFileSize=10M -Xloggc:/logs/kyuubi-server.gc.log"`
        
    - `export KYUUBI_BEELINE_OPTS="-Xmx2g -XX:+UseG1GC -XX:+UnlockDiagnosticVMOptions -XX:+UseCondCardMark"`
