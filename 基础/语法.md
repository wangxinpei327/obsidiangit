|比较字符串|`a.equals(b)`|`a == b`|
|字符串拼接|`StringBuilder`|循环中频繁使用 `+`|

|`split("|")`|`split("\\|

# 20. 笔试最容易忘记的知识点

- `String` 比较内容必须使用 `equals()`，不要使用 `==`
    
- `ArrayList` 获取元素用 `get(i)`，不能用 `list[i]`
    
- `HashMap` 统计频率优先使用 `getOrDefault()`
    
- `PriorityQueue` 默认是**小根堆**
    
- `Arrays.sort(int[])` 不能直接降序，如需降序请使用 `Integer[]`
    
- `ArrayDeque` 不允许存放 `null`
    
- `Arrays.asList()` 返回的是固定长度列表，不能直接 `add()` 或 `remove()`
    
- 整数除法会截断小数，例如 `5 / 2 == 2`
    
- 涉及大数据范围（如 `10^9`、`10^12`）时，优先使用 `long`，并注意表达式提升，例如写成 `1L * a * b`
